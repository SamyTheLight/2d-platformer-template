# 2d-platformer-template

Plantilla para Godot 4.7 orientada a crear y prototipar juegos de plataformas 2D con una base sencilla y reutilizable.

## Contenido previsto

- **Movimiento:** desplazamiento horizontal con aceleración y frenado, gravedad y salto de altura variable, con margen para saltar al salir de un borde y memoria de pulsación antes de aterrizar.
- **Assets de prototipado:** personaje con animaciones básicas, piezas de terreno y plataformas, fondo y decoración sencillos, fáciles de sustituir.
- **Escena de prueba:** un nivel pequeño para comprobar el movimiento y construir los primeros obstáculos.
